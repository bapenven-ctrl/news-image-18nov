One image that sums up the world news of Wednesday 18 November 2026,
drawn as a broadsheet front page: "THE WORLD IN ONE PAGE". Forty-six
verified stories — sixteen illustrated panels (the APEC opening in
Shenzhen; Iran's strikes on the U.S. base in Kuwait and sites in
Bahrain; Trump–Marcos in Manila; the AI markets day with Anthropic's
$81.3bn IPO pricing and Nvidia's fall; Cyclone Akvan; Ukraine's
141-drone night; Voyager 1 reaching one light-day; the U.S.–Venezuela
military pact; the EU's proposed €45bn Ukraine loan; the Fed minutes;
UK inflation at 3.6%; GTA VI's launch day; COP31 in Antalya; Ebola in
DR Congo; Alcaraz–Medvedev in Turin; Cyclone Xavier) plus thirty
numbered briefs, a pin-numbered world map, a UTC timeline, key numbers
and a black DATE CHECK footer listing what was checked and left out.
Every headline is set in real type — the image was rendered
deterministically with Pillow, never AI-generated, so no text is garbled.

The entry program is deliberately simple: `main.py` (Python 3.13,
standard library only) copies the committed `entry.png` to the
output path, so both harness runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
